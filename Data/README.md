# Data

`hr-feed.csv` is the single source of truth for Danotech Inc's workforce. Every phase reads from it; nothing else creates users.

All 200 people are **fictional**. Names were generated for this lab and any resemblance to real people is coincidental.

Column definitions and the Entra ID mapping are in [`../docs/hr-feed-mapping.md`](../docs/hr-feed-mapping.md).
